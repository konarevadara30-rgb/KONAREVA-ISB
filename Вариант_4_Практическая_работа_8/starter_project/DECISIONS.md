# DECISIONS

1. Статус меняется только через методы `submit`, `approve`, `reject`, `cancel`, `complete`, а setter для статуса нет. В каждом методе сначала проверяется текущий статус, и при недопустимом переходе выбрасывается `IllegalStateException`, а объект не меняется.
2. Неверные данные (пустой id, дата окончания раньше начала, причина отклонения короче 25 символов по варианту 4) дают `IllegalArgumentException`. Даты проверяются в конструкторе, поэтому заявку с неправильными датами нельзя даже создать.
