# DECISIONS

1. В `parseHours` строка делится через `split(";", -1)`, чтобы пустые значения в конце строки тоже считались. Тогда строка `8;8;8;8;8;` не пройдёт проверку на ровно 5 значений.
2. При ошибке выбрасывается `IllegalArgumentException` с номером позиции (с 1). Весь табель считается некорректным, но пользователь видит, в каком именно дне ошибка.
